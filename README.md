# ซอมบี้สวนยาง ออนไลน์

- `server/` เซิร์ฟเวอร์รีเลย์ WebSocket สำหรับ Render (Root Directory = `server`, Build = `npm install`, Start = `npm start`)
- `docs/index.html` หน้าเกม สำหรับ GitHub Pages (Source = `main` branch, folder `/docs`)

ก่อนใช้งาน แก้ค่า `RELAY` ใน `docs/index.html` ให้เป็นลิงก์ของ Render โดยเปลี่ยนจาก `https://` เป็น `wss://`
